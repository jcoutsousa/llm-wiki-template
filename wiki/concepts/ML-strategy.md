# ML Strategy

## Definition

Systematic approach to machine learning development focusing on problem formulation, error diagnosis, and iterative improvement rather than technical implementation.

## Key Principles

- Build first system quickly, then iterate
- Use error analysis to guide improvements
- Focus on data and evaluation metrics before scaling
- Diagnose bias vs variance through learning curves
